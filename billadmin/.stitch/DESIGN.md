# Design System: BillFlow SaaS Admin Panel
**Project ID:** 18136933643213772534

## 1. Visual Theme & Atmosphere
The design system focuses on high-precision efficiency, sophisticated control, and immense readability. It is built for SaaS platform administrators who require a deep-focus dashboard. The theme is **Obsidian Command Center**, employing dark slate interfaces that float over an infinite dark space. Tonal shifts and luminous accents are used to define boundaries instead of generic borders.

## 2. Color Palette & Roles
- **Obsidian Navy Background (#0B0F19)**: The dark, infinite base.
- **Deep Charcoal Surface (#111827)**: Used for cards and panels sitting above the base.
- **Emerald Teal (#0D9488)**: Dedicated to active status, successful operations, and primary interactive CTAs.
- **Electric Blue (#2563EB)**: Used for secondary visual connections, charts, indicators, and minor action states.
- **Light Slate Text (#DEE5FF)**: Main text color for headers and labels.
- **Muted Gray-Slate Text (#94A3B8)**: Default description, timestamps, and placeholder details.

## 3. Typography Rules
- **Geist (Headlines)**: Technical and sharp geometric sans-serif for displays and headers.
- **Inter (Body/Data)**: Workhorse for data tables and notes to maximize reading clarity.
- **JetBrains Mono (Metadata)**: Monospaced typography for license keys, reference codes, UTR, and audit logging metrics.

## 4. Component Stylings
- **Buttons**:
  - *Primary*: Solid Emerald Teal background with white text, rounded-lg (8px), glowing outline on hover.
  - *Secondary*: Border border-gray-300 dark:border-slate-800 with Electric Blue text.
- **Cards/Containers**: No borders, rounded-xl (12px), background of Deep Charcoal (#111827) floating on Obsidian Navy.
- **Inputs/Forms**: Deep Navy background (#0B0F19) with a thin gray-slate outline, shifting to Emerald Teal highlight on focus.

## 5. Layout Principles
Modules and tables float in a centered dashboard layout. Generous padding prevents high density data from looking cluttered.
