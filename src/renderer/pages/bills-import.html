Import Bills

CSV Import Guidelines

To import bills from previous platforms like Tally, Odoo, Zoho, or Miracle, please export your invoices to a CSV file. The columns in your CSV should map to the fields below. A single bill with multiple line items should have the same bill_number across multiple rows.

Supported CSV Headers:

bill_number (Required)
item_name (Required)
bill_date (Required, YYYY-MM-DD)
item_qty (Required, number)
customer_name (Required)
item_rate (Required, number)
customer_state (Required)
item_gst_rate (Required, e.g. 18)
customer_gstin (Optional)
item_hsn (Optional)
customer_address (Optional)
item_discount (Optional, %)
customer_phone (Optional)
due_date (Optional, YYYY-MM-DD)
